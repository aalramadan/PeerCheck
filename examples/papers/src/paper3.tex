\author{\IEEEauthorblockN{Lena Brandt}\IEEEauthorblockA{University of Nowhere\\lena.brandt@uni-nowhere.edu}}

\begin{abstract}
Flaky tests pass and fail on the same code. FlakeScope ranks the failures of a build by the chance that each
failure is flaky. In our previous work [1], we built the data set that this paper uses.
\end{abstract}
